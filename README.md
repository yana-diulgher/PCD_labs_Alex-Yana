# Лабораторная работа №1 — вариант 7

## Участники
- Турятко Александр
- Дюльгер Яна
- Группа CR-243

## Структура
- `Potok1.java` — первое условие варианта 7: суммирование чётных чисел попарно с начала массива.
- `Potok2.java` — второе условие варианта 7: перемножение чётных чисел попарно с конца массива и суммирование полученных произведений.
- `Student1.java` — два потока Александра.
- `Student2.java` — два потока Яны.
- `OknoProgrammy.java` — графический интерфейс, общий массив, запуск потоков и вывод результатов.
- `Main.java` — точка входа.

## Запуск
Откройте папку проекта в IntelliJ IDEA и запустите `Main`.

## Логика
Создаётся один массив из 100 случайных целых чисел в диапазоне от 1 до 100.
Каждый студент запускает два потока (`Runnable`), поэтому всего работает четыре потока.
Все четыре потока читают один и тот же массив. После запуска главный рабочий процесс ожидает завершения потоков с помощью `join()`.
После завершения всех потоков имена участников выводятся по буквам с интервалом 100 мс с помощью Swing Timer.
